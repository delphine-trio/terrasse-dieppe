# Images du site

Chaque image est appelée par son nom dans les fichiers HTML. Tant qu'un fichier est absent, un cadre gris affiche le nom attendu.

Pour remplacer une image : copiez votre photo ici avec **exactement le nom indiqué** (extension comprise), puis git add / commit / push.
Si votre photo est en .jpeg ou .png alors que le nom attendu est .jpg, renommez-la, ou modifiez le nom dans le HTML.

Conseil : largeur max 1600 px, moins de 300 Ko, sans accent ni espace.
